# FAQ

<details>
<summary><strong>Is Hermes Agent free?</strong></summary>

<br>

The agent is MIT open source and free to run yourself. Model providers and optional Nous Portal hosted features have their own pricing. Source: [official FAQ](https://hermes-agent.nousresearch.com/).

</details>

<details>
<summary><strong>Who builds it?</strong></summary>

<br>

[Nous Research](https://nousresearch.com). Repo: [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent).

</details>

<details>
<summary><strong>Does it run on Windows?</strong></summary>

<br>

Yes, natively via the PowerShell installer, or via WSL2 with the Linux installer. Source: [README](https://github.com/NousResearch/hermes-agent).

</details>

<details>
<summary><strong>Where do I get models?</strong></summary>

<br>

Use `hermes model` or `hermes setup --portal`. Providers include Nous Portal, OpenRouter, OpenAI, and many others listed in [providers docs](https://hermes-agent.nousresearch.com/docs/integrations/providers).

</details>

<details>
<summary><strong>Is this repo official?</strong></summary>

<br>

No. This is an independent community guide. Official docs live at [hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs/).

</details>

<details>
<summary><strong>Are community skills safe?</strong></summary>

<br>

Not automatically. Review source, use approvals and sandboxes, and read [security.md](security.md).

</details>
