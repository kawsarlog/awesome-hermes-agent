# Glossary

<p align="center">
  <img src="../assets/sections/sec-glossary.png" alt="Glossary" width="100%">
</p>

| Term | Plain meaning | Source |
|------|---------------|--------|
| Hermes Agent | Self-improving AI agent by Nous Research | [site](https://hermes-agent.nousresearch.com/) |
| Skill | Reusable procedural knowledge (often `SKILL.md`) | [skills docs](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills) |
| agentskills.io | Open standard / hub for portable skills | [agentskills.io](https://agentskills.io) |
| Gateway | Process that connects Hermes to chat apps | [README](https://github.com/NousResearch/hermes-agent) |
| Nous Portal | Official models + Tool Gateway + optional cloud hosting | [portal](https://portal.nousresearch.com) |
| Tool Gateway | Hosted search/images/speech/browser via Portal | [docs](https://hermes-agent.nousresearch.com/docs/user-guide/features/tool-gateway) |
| MCP | Model Context Protocol for extra tools/servers | [MCP docs](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp) |
| Subagent | Isolated helper agent for parallel work | [README](https://github.com/NousResearch/hermes-agent) |
| Backend | Where terminal commands run (local, Docker, SSH, Modal, ...) | [README](https://github.com/NousResearch/hermes-agent) |
| Cron / Blueprints | Scheduled or templated automations | [cron docs](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron) |
| Honcho | Dialectic user modeling / memory library | [plastic-labs/honcho](https://github.com/plastic-labs/honcho) |
| Curator | Built-in maintenance of the skill library (mentioned in community guides for recent releases) | Confirm in [releases](https://github.com/NousResearch/hermes-agent/releases) |
| Desktop | Native Hermes app for macOS / Windows / Linux | [site](https://hermes-agent.nousresearch.com/) |
| Termux | Android install path via APT channels | [Termux guide](https://hermes-agent.nousresearch.com/docs/getting-started/termux) |
