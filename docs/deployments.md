## Official options

| Option | Notes | Source |
|--------|-------|--------|
| Local laptop | Default installers | [install docs](https://hermes-agent.nousresearch.com/docs/getting-started/installation) |
| Desktop app | macOS / Windows / Linux | [site](https://hermes-agent.nousresearch.com/) |
| $5 VPS / GPU cluster | Supported messaging; agent not tied only to laptop | [README](https://github.com/NousResearch/hermes-agent) |
| Serverless backends | Modal, Daytona, Vercel Sandbox (hibernate when idle) | README |
| Nous Portal cloud agent | Optional hosted agent sizes on paid tiers | [site pricing](https://hermes-agent.nousresearch.com/) |
| Termux | Android APT `stable` / `canary` | [Termux guide](https://hermes-agent.nousresearch.com/docs/getting-started/termux) |
