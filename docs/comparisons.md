## Hermes in one sentence

Self-improving, open-source agent (MIT) from Nous Research with persistent memory, skills learning loop, messaging gateway, cron, MCP, and multiple sandbox backends. Sources: [site](https://hermes-agent.nousresearch.com/), [repo](https://github.com/NousResearch/hermes-agent).

## Migrating from OpenClaw, Claude Code, Codex, Cursor

Hermes can import settings, memories, and skills from those agents (and OpenClaw API keys when asked). Official commands and file lists: [migrate from OpenClaw](https://hermes-agent.nousresearch.com/docs/guides/migrate-from-openclaw), [import from other agents](https://hermes-agent.nousresearch.com/docs/user-guide/import-from-other-agents), [README](https://github.com/NousResearch/hermes-agent).

Community helper (optional): [0xNyk/openclaw-to-hermes](https://github.com/0xNyk/openclaw-to-hermes) (40 stars on 2026-11-04 Asia/Dhaka).

## What Hermes emphasizes that beginners notice

| Theme | Hermes claim (sourced) |
|-------|------------------------|
| Learning loop | Creates/improves skills from experience | 
| Runs off-laptop | VPS, GPU cluster, serverless backends; chat from Telegram while it works on a VM |
| Many surfaces | Telegram, Discord, Slack, WhatsApp, Signal, Email, CLI, Desktop |
| Open models | Bring Nous Portal, OpenRouter, OpenAI, local endpoints, and more; `hermes model` to switch |
| License | MIT |

Sources: README + official site.
