# Learning path

## Beginner (day 1)

- [ ] Read [getting-started.md](getting-started.md)
- [ ] Install from [install.md](install.md)
- [ ] Finish one safe chat
- [ ] Skim [security.md](security.md)
- [ ] Star [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) if it helps you (optional)

## Intermediate (week 1)

- [ ] Enable a few tools with `hermes tools`
- [ ] Install one reviewed skill from [skills.md](skills.md)
- [ ] Read [memory.md](memory.md) and tidy USER/MEMORY notes
- [ ] Try cron once ([workflows.md](workflows.md))
- [ ] Optional: Desktop or [nesquena/hermes-webui](https://github.com/nesquena/hermes-webui)

## Power user

- [ ] MCP servers via `hermes mcp`
- [ ] Subagents for parallel work
- [ ] Isolated backends for risky jobs
- [ ] Fleet UI such as [mission-control](https://github.com/builderz-labs/mission-control)
- [ ] Compare notes in [comparisons.md](comparisons.md)
