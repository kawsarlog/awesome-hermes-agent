# Cheat sheet

```bash
# install
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash   # macOS/Linux/WSL2
# Windows PowerShell: iex (irm https://hermes-agent.nousresearch.com/install.ps1)

source ~/.bashrc
hermes
hermes setup --portal
hermes model
hermes tools
hermes mcp
hermes gateway setup
hermes doctor
hermes update
```
