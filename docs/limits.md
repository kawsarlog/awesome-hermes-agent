## Product facts

- Hermes Agent is free/MIT. Model APIs and Nous Portal tiers are separate costs. Source: [site FAQ](https://hermes-agent.nousresearch.com/).
- Hosted Portal features (models, Tool Gateway, cloud agent size) depend on Free / Plus / Super / Ultra. Re-read the live pricing table before you buy. Source: [site](https://hermes-agent.nousresearch.com/).
- Stopping a local agent stops running jobs; it does not wipe memory/skills. Source: [site FAQ](https://hermes-agent.nousresearch.com/).
- Community skills can be powerful and risky. Listings are not endorsements. Source: [security docs](https://hermes-agent.nousresearch.com/docs/user-guide/security).

## This repo's limits

- Independent community guide. Not affiliated with Nous Research.
- We verify links when building, but the web changes. Open an issue if something breaks.
- Star counts are snapshots with dates. They go stale.
- We do not invent menus, prices, or commands.
